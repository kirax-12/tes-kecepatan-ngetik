# Tes Kecepatan Ngetik

**Demo live:** [tes-kecepatan-ngetik di GitHub Pages](https://kirax-12.github.io/tes-kecepatan-ngetik/)

Tes kecepatan mengetik Bahasa Indonesia langsung di browser. Pilih durasi 30 atau 60 detik, ketik kalimat yang muncul, lalu lihat skor WPM dan akurasimu — lengkap dengan penilaian lucu dan kartu hasil yang bisa dibagikan.

## Fitur

- **Dua mode durasi:** 30 detik dan 60 detik, waktu mulai berjalan dari ketikan pertama.
- **Kalimat Bahasa Indonesia acak** dari kumpulan 16 kalimat (ada tanda baca dan angka), disambung otomatis kalau hampir habis sebelum waktu selesai.
- **Penanda per karakter:** hijau kalau benar, merah kalau salah, karakter aktif bergaris bawah — jadi kelihatan persis salahnya di mana.
- **Statistik langsung:** WPM, akurasi, dan sisa waktu diperbarui sambil kamu mengetik.
- **Skor WPM standar:** karakter benar ÷ 5 ÷ menit, sama seperti tes mengetik pada umumnya.
- **Penilaian lucu** sesuai skor: Mode Kura-Kura, Lumayan Ngacir, Jari Kilat, sampai Dewa Keyboard.
- **Kartu hasil PNG 1080×1080** yang bisa diunduh dan dibagikan ke WhatsApp.
- **Anti-tempel:** paste dimatikan di kolom ketik, biar skornya jujur.
- Bisa dimainkan di HP — kolom ketik memanggil keyboard layar seperti biasa.

## Cara Main

1. Pilih durasi: 30 atau 60 detik.
2. Klik kotak teks, lalu ketik kalimat yang tampil persis seperti contohnya (termasuk tanda baca dan spasi).
3. Waktu habis, hasilmu muncul: WPM, akurasi, jumlah karakter benar dan salah.
4. Unduh kartu hasil atau bagikan ke WhatsApp, lalu tekan **Ulangi** buat coba lagi.

## Cara Menjalankan

Cukup buka `index.html` di browser — tidak perlu server, build step, atau instalasi apa pun. Semua berjalan lokal di perangkatmu.

## Teknologi

- HTML, CSS, dan JavaScript murni (tanpa framework).
- Canvas API untuk menggambar kartu hasil PNG.
- Font Space Grotesk, Space Mono, dan Caveat dari Google Fonts.
- Gaya visual neo-brutalist krem khas Remike Dev.
